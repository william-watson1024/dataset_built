
后面我们的数据主要有三种用途：训练、评测、分析。

训练时不会直接拿 Canonical JSONL 喂模型，而是再做一层很薄的适配：

```text
processed/<dataset>/
├── train.jsonl
└── media/

        ↓

Canonical Sample
        ↓
Training Adapter
        ↓
ms-swift / transformers 需要的格式
        ↓
QLoRA / SFT
```

例如：

```json
{
  "input": {
    "images": ["media/10095.png"],
    "prompt": "How many values are below 40?"
  },
  "output": {
    "text": "6"
  }
}
```

训练前转换成类似：

```text
user:
<image>
How many values are below 40?

assistant:
6
```

然后多个数据集一起训练时，不需要把它们物理合成一个大文件，可以通过一个混合配置控制：

```yaml
datasets:
  docvqa:
    path: processed/docvqa/train.jsonl
    weight: 1.0

  chartqa:
    path: processed/chartqa/train.jsonl
    weight: 1.0

  mmtab:
    path: processed/mmtab/train.jsonl
    weight: 1.5
```

评测则走另一条链：

```text
validation / test
↓
模型生成 prediction
↓
对应 evaluator
↓
ANLS / Accuracy / F1 / ROUGE ...
```

所以最终结构可以理解为：

```text
Raw Dataset
↓
Canonical processed 数据
├── 用于训练
├── 用于评测
└── 用于统计 / 去重 / 消融实验
```

核心价值就是：以后换 Gemma、Qwen、InternVL，或者换 ms-swift / Transformers，都不用重新处理原始数据，只需要换最后一层 Adapter。
